# Noxe — Legal

Public legal pages for the Noxe app (privacy policy, terms, community guidelines, attributions).
Source of truth lives in the app repo at `legal/index.html`; this repo exists to serve it over
GitHub Pages so the App Store / Play Store have a stable public URL.

- Privacy Policy: `/#privacy`
- Terms of Use: `/#terms`
- Community Guidelines: `/#guidelines`
- Data & attributions: `/#attributions`
